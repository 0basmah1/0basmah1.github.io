Automatic Car Parking Gate

This project is about creating an automatic car parking gate system by using an Arduino board , an ultrasonic sensor, LED and a buzzer.
The main goal is to make the sensor work by measuring the distance between the sensor and the car.
So when the car approaches the gate within 10 cm or less, the sensor will detect it, and the Arduino will respond by activating a buzzer and LED activating the servo motor to open the gate.
This model is simple, cost-effective system provides an efficient way for automatic parking gate and can be improved in the future.
